# Experimental HEP Workflows

This repository contains software setup guides, example codes, and computational workflows used in **Experimental High Energy Physics (HEP)**.

The aim is to document commonly used tools and methods for particle physics simulations, data analysis, machine learning, statistical inference, and detector studies.

## Contents

### 1. Software Installation & Setup
Installation and configuration of scientific software, including:
- MadGraph5_aMC@NLO,LHAPDF6, Pythia8, and Delphes
- ROOT and TMVA
- CMSSW and CMS Combine
- Supporting libraries and computing environments

### 2. Monte Carlo Simulations
General workflows for event generation, parton showering, and detector simulation.

### 3. ROOT Data Analysis
Example scripts for event processing, histogramming, and visualization of physics distributions.

### 4. Machine Learning
Examples of binary and multiclass BDT classification, training and testing, and performance evaluation using TMVA.

### 5. Statistical Analysis
Example datacards, binned likelihood analysis, uncertainty modelling, and statistical inference using CMS Combine.

### 6. Detector Studies
General documentation related to CMS Phase-II 2S module testing, electrical characterization, and performance studies.
