# Experimental HEP Workflows

This repository contains software setup guides, example codes, and computational workflows used in **Experimental High Energy Physics (HEP)**.

The aim is to document commonly used tools and methods for particle physics simulations, data analysis, machine learning, statistical inference, and detector studies.

## Contents

### [1. Software Installation & Setup](Software_Installation/)
Installation and configuration of scientific software, including:
- MadGraph5_aMC@NLO,LHAPDF6, Pythia8, and Delphes
- ROOT and TMVA
- CMSSW and CMS Combine
- Supporting libraries and computing environments

### [2. Monte Carlo Simulations](Monte_Carlo_Simulation/)
General workflows for event generation, parton showering, and detector simulation.

### [3. HTCondor Batch Production](HTCondor_Batch_Production/)

HTCondor-based batch processing workflows for automated Monte Carlo event generation, parallel job submission, resource management, and large-scale simulation production.

### [4. ROOT Data Analysis](ROOT_Analysis/)
ROOT/C++ analysis workflows for event processing, histogramming, and visualization of physics distributions.

### 5. Machine Learning
TMVA-based workflows for binary and multiclass BDT classification, model training, testing, and performance evaluation.

### 6. Statistical Analysis
CMS Combine workflows covering datacard preparation, binned likelihood analysis, uncertainty modelling, and statistical inference.

### 7. Detector Studies
General documentation related to CMS Phase-II 2S module testing, electrical characterization, and performance studies.
